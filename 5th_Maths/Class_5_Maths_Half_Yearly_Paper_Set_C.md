#### Multiple Choice Questions / बहुविकल्पीय प्रश्न

**(5 × 1 = 5 Marks)**

**Q1. The place value of the digit $6$ in the number $8,65,420$ is:**  
**संख्या $8,65,420$ में अंक $6$ का स्थानीय मान है:**  
(a) $600$  
(b) $6,000$  
(c) $60,000$

(a) $1$  
(b) $2$  
(c) $3$  
(d) $4$  

**Q3. A fraction whose numerator is $1$ (such as $\frac{1}{3}, \frac{1}{5}$) is known as a:**

(b) Proper fraction / उचित भिन्न  
(c) Mixed fraction / मिश्रित भिन्न  
(d) Like fraction / समान भिन्न  

**Q4. Which of the following numbers is a factor of $30$?**

(a) $4$  
(b) $6$  
(c) $7$  
(d) $8$  

**Q5. $2\text{ cm and } 5\text{ mm}$ written in centimetres using decimals is:**  
**$2$ सेमी और $5$ मिमी को दशमलव का प्रयोग कर सेंटीमीटर में लिखने पर मान होगा:**
